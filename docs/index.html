Share Simulators with Your Students

Get a public web link so students can open this anywhere

Live Classroom Link & QR Code Scan with phone camera
QR ready once URL is pasted
Students can point their phone or tablet camera at this QR code to launch the simulator directly.

Choose your preferred free hosting method below to get a permanent link for your students:

1
Option A: Netlify Drop (Fastest — 30 Seconds, No Code)

Simply drag your Simulations folder into your web browser:

  1. Go to app.netlify.com/drop in your browser.
  2. Drag and drop your entire Simulations folder into the drop zone.
  3. Instantly get a live link (e.g. https://my-science-sims.netlify.app) to paste above!
2
Option B: Classroom Wi-Fi (No Internet Needed!)

Share with students in your classroom over local school Wi-Fi:

Double-click run_local_server.bat inside your folder. It will start a local server and give you an IP link (e.g. http://192.168.1.50:8000) that all connected students can open immediately!

3
Option C: GitHub Pages (Permanent & 100% Free)

Publish permanent links for your syllabus or class portal:

  1. Create a new Public repository on github.com (e.g. simulations).
  2. Upload all files from this folder (make sure index.html is in the root directory).
  3. In your repo, go to Settings → Pages.
  4. Under Build and deployment, set Source to Deploy from a branch, select branch main, and click Save.
  5. Wait ~60 seconds. Your permanent URL will be: https://<your-username>.github.io/simulations/

See README.md for full terminal instructions, Canvas/LMS embed codes, and troubleshooting.

How to Add a New Simulator

Expand your library in just 2 simple steps

1
Save your new simulator HTML file

Place your new simulator file (e.g. Lac Operon Simulator.html) in this exact same Simulations folder.

2
Add an entry to the SIMULATIONS list

Open index.html in any text editor and add a new item to the SIMULATIONS array (around line 1050): 

{
  id: "lac-operon",
  title: "Lac Operon Gene Regulation",
  filename: "Lac Operon Simulator.html",
  category: "genetics",
  tags: ["Genetics", "Transcription", "Negative Feedback"],
  description: "Investigate lactose induction, CAP-cAMP activation, and repressor binding.",
  features: ["Inducer kinetics", "Glucose effect", "Mutant alleles"],
  badge: "Active",
  gradient: "linear-gradient(135deg, #1C3B61 0%, #2A6BB2 100%)"
}
